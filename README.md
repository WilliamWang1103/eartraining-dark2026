# 🎵 音乐听觉综合训练系统

> 内蒙古民族大学音乐学院学习陪伴程序

一个专业的音乐听力训练Web应用，支持单音听辨、音程听辨、和弦听辨、节奏听辨和旋律听辨等多种练习模式。

## ✨ 最新功能：MIDI 键盘支持

**🎹 v1.1.0 新增：** 完整支持 MIDI 键盘输入！

- ✅ 实时音符输入，延迟 < 100ms
- ✅ 自动设备检测和热插拔
- ✅ 多设备同时支持
- ✅ 视觉反馈同步高亮
- ✅ 跨所有练习模式支持

详见：[快速启动指南](快速启动.md) | [MIDI使用指南](MIDI使用指南.md)

## 📋 功能特性

### 🎯 练习模式

1. **单音听辨** - 训练单个音符的辨识能力
2. **音程听辨** - 练习音程距离的感知
3. **和弦听辨** - 和弦性质和组成的识别
   - 音准听辨：识别和弦中的各个音符
   - 性质听辨：判断和弦类型（大三、小三、属七等）
4. **节奏听辨** - 节奏型的辨识和记忆
5. **旋律听辨** - 旋律线条的听写能力

### 🎮 练习方式

- **练习模式** - 自由练习，即时反馈
- **测试模式** - 20题标准化测试，生成成绩报告
- **单元测验** - 阶段性能力评估（开发中）

### 🎹 钢琴键盘

- 完整的虚拟钢琴界面（G3-F5，共23个音符）
- 支持鼠标点击和 **MIDI 键盘输入**
- 实时视觉反馈和高亮显示
- 可配置的调式限制（8个难度级别）

### 📊 学习分析

- 详细的测试成绩报告
- 错误分析和薄弱环节识别
- 个性化学习建议
- 历史成绩追踪

### 👤 学生管理

- 学生信息保存和加载
- 本地存储，保护隐私
- 教师信息管理

## 🚀 快速开始

### 前置要求

- 现代浏览器（Chrome/Edge 推荐）
- Web Audio API 支持
- （可选）MIDI 键盘用于 MIDI 输入

### 安装和运行

```bash
# 克隆或下载项目
cd APP_EarTrainingPractice_test

# 方法1：使用 Python 启动本地服务器
python3 -m http.server 8080

# 方法2：使用 Node.js
npx http-server -p 8080

# 方法3：使用 PHP
php -S localhost:8080
```

然后在浏览器中访问：`http://localhost:8080`

> ⚠️ **重要：** 必须通过 HTTP/HTTPS 访问，直接打开 HTML 文件可能导致部分功能无法使用。

### 使用 MIDI 键盘

1. 连接 MIDI 键盘到电脑
2. 刷新页面，检查状态指示器
3. 开始练习，按下琴键即可输入音符

详见：[MIDI快速启动指南](快速启动.md)

## 🐛 常见问题

### Q: MIDI 键盘无法识别？
A: 
- 确保使用 Chrome/Edge 浏览器
- 检查浏览器是否授予 MIDI 权限
- 尝试重新插拔 USB 线
- 查看控制台错误信息

### Q: 没有声音？
A:
- 检查系统音量和浏览器音量
- 点击页面任意位置激活音频上下文
- 确认扬声器/耳机正常工作

### Q: 琴键不高亮？
A:
- 检查音符是否在 G3-F5 范围内
- 确认 DOM 元素正确生成
- 查看浏览器控制台是否有错误

更多问题请参考：[MIDI功能测试.md](MIDI功能测试.md)
